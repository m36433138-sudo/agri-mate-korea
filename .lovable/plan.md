# 작업현황판 S/N 분리

## 변경 내용
- 구글 시트의 현재 S/N 위치를 더 이상 제조번호로 해석하지 않고 고객 요구사항 데이터로 유지합니다.
- 작업현황판의 S/N은 앱 내부 작업 기록에만 저장하며, 최초에는 비어 있도록 합니다.
- 작업 추가·수정 화면에서 S/N을 별도로 입력하고 수정할 수 있게 합니다.
- 목록은 앱 내부 S/N만 표시하며, 구글 시트에서 읽거나 시트로 쓰지 않습니다.
- 기존 시트 열 순서를 바꾸지 않아 현재 작업 데이터와 상태 변경 흐름을 보호합니다.

## 저장 및 연결 기준
- 지점과 시트 행 번호를 기준으로 기존 작업 기록과 S/N을 연결합니다.
- 작업 삭제 시 앱 내부의 해당 작업 기록도 함께 정리합니다.
- 저장 실패 시 어느 쪽이 실패했는지 사용자에게 알리고 잘못된 완료 안내를 표시하지 않습니다.

## 확인
- 새 작업은 S/N이 빈 상태로 표시되는지 확인합니다.
- S/N 입력·수정 후 새로고침해도 유지되는지 확인합니다.
- 고객 요구사항이 S/N으로 잘못 표시되거나 덮어써지지 않는지 확인합니다.
