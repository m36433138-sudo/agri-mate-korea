# 기계 상세 사진 등록

## 구현 내용
- 기계 상세 화면에 사진 영역을 추가해 휴대폰 촬영과 여러 이미지 선택을 지원합니다.
- 업로드 전 긴 변을 최대 1600px로 줄이고 JPEG 품질을 조정해 용량을 절약합니다.
- 등록된 사진은 작은 미리보기로 표시하고, 눌러 크게 보기와 개별 삭제를 지원합니다.
- 기계별 사진 정보와 전용 비공개 저장 공간을 만들고 관리자·직원만 등록/삭제할 수 있게 보호합니다.

## 확인
- 실제 기계 상세 화면에서 사진 선택, 축소 업로드, 미리보기, 확대 보기, 삭제 흐름을 확인합니다.
- 휴대폰과 데스크톱 크기에서 사진 영역이 깨지지 않는지 확인합니다.

## 기술 세부사항
- 사진 메타데이터는 기계 ID와 연결해 저장합니다.
- 원본 파일은 브라우저에서 Canvas로 축소·압축한 뒤 업로드하며, 이미 작은 이미지는 불필요하게 확대하지 않습니다.
- 업로드 실패 시 저장된 파일이나 목록 정보가 한쪽에만 남지 않도록 정리합니다.
